# Megalo peos
Goal of this desktop application is separating engineers equipment and accounting technical equipment. There are 3 roles for users: manager(adds equipment and observes its status), administrator(adds users), engineer(changes status of his own item)

## Stack:
+ C# .NET
+ WPF
+ Entity Framework Core
+ Material Design Themes
